# in English

# Cash Balance

Cash Balance is an application for convenient calculation, tracking, and management of in-game funds in GTA 5 Majestic RP.
The app helps you quickly determine the total amount of cash and other funds, track transaction history, and monitor your in-game balance.

# 🎮 Features

* 📊 Total capital calculation
* ➕ Add income
* ➖ Add expenses
* 📋 Transaction history
* 🔄 Quick balance recalculation
* 💾 Save entered data
* 📈 Convenient capital change tracking

# 🚀 Installation

1. Download the latest version of Cash Balance
2. Run Cash_Balance.exe
3. Use the application for further tracking

# 🎯 Who the application is for

Cash Balance is useful for **Majestic RP** players who:
* want to monitor their in-game capital;
* run a business or actively earn money;
* frequently make large purchases;
* want to see their income and expense history;
* are saving up for a specific amount;
* want to quickly recalculate their capital.

#❗IMPORTANT❗

Cash Balance is an auxiliary tool for personal tracking of in-game funds.
The application is not affiliated with the Majestic RP banking system, does not alter in-game balances, and does not provide any in-game advantages.
All data entered by the user is intended solely for convenient personal calculation.

# На русском

# Cash Balance

Cash Balance — приложение для удобного подсчёта, учёта и контроля денежных средств в игре GTA 5 Majestic RP.
Приложение помогает быстро определить общую сумму наличных и других денежных средств, вести историю операций и контролировать свой игровой баланс.


# 🎮 Возможности 

* 📊 Расчёт общей суммы капитала
* ➕ Добавление доходов
* ➖ Добавление расходов
* 📋 История денежных операций
* 🔄 Быстрый пересчёт баланса
* 💾 Сохранение введённых данных
* 📈 Удобный контроль изменения капитала


# 🚀 Установка

1. Скачайте последнюю версию Cash Balance
2. Запустите Cash Balance.exe
3. Используйте приложение для дальнейшего учёта


# 🎯 Для кого предназначено приложение

Cash Balance будет полезен игрокам **Majestic RP**, которые:
* хотят контролировать свой игровой капитал;
* ведут бизнес или активно зарабатывают;
* часто совершают крупные покупки;
* хотят видеть историю доходов и расходов;
* копят определённую сумму денег;
* хотят быстро пересчитывать свой капитал.


#❗ВАЖНО❗

Cash Balance является вспомогательным инструментом для личного учёта игровых денежных средств.
Приложение не связано с банковской системой Majestic RP, не изменяет игровой баланс и не предоставляет преимуществ в игре.
Все данные, введённые пользователем, предназначены исключительно для удобного личного подсчёта.
