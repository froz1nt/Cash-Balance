# Cash Balance

Cash Balance — приложение для удобного подсчёта, учёта и контроля денежных средств в игре GTA 5 Majestic RP.
Приложение помогает быстро определить общую сумму наличных и других денежных средств, вести историю операций и контролировать свой игровой баланс.


# 🎮 Возможности 

* 📊 Расчёт общей суммы капитала
* ➕ Добавление доходов
* ➖ Добавление расходов
* 📋 История денежных операций
* 🔄 Быстрый пересчёт баланса
* 💾 Сохранение введённых данных
* 📈 Удобный контроль изменения капитала


# 🚀 Установка

1. Скачайте последнюю версию Cash Balance.
2. Установите приложение.
3. Запустите Cash Balance.
4. Введите текущие денежные средства своего персонажа.
5. Используйте приложение для дальнейшего учёта.


# 🎯 Для кого предназначено приложение

Cash Balance будет полезен игрокам **Majestic RP**, которые:
* хотят контролировать свой игровой капитал;
* ведут бизнес или активно зарабатывают;
* часто совершают крупные покупки;
* хотят видеть историю доходов и расходов;
* копят определённую сумму денег;
* хотят быстро пересчитывать свой капитал.


# ❗❗❗ Важно ❗❗❗

Cash Balance является вспомогательным инструментом для личного учёта игровых денежных средств.
Приложение не связано с банковской системой Majestic RP, не изменяет игровой баланс и не предоставляет преимуществ в игре.
Все данные, введённые пользователем, предназначены исключительно для удобного личного подсчёта.
